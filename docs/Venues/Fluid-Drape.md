# Fluid + Drape

Fluid + Drape is a fabric and fiber creative space at 4216 West 7th Ave, Unit J in Eugene, Oregon. They host semi-annual open houses with fabric sales, remnant sales, and seasonal marketplaces featuring local creative vendors. [@fluidplusdrape](https://www.instagram.com/fluidplusdrape)
