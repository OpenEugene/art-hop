# Shadowfox

Shadowfox is the artist name of Jason Pancoast, a Eugene artist who creates elaborate layered sculptural paintings celebrating nature, landscape, and geometry. Visit Shadowfox for a tour of the artist's studio in a beautiful studio and gallery setting. If you're lucky you'll catch some live music and performance too! [View Shadowfox's website here.](https://www.shadowfoxdesign.com/)
